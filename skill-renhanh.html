1. Vấn đề cần giải quyết

Khi làm việc với AI Agent (Antigravity, Cursor, Windsurf...), cuộc trò chuyện càng dài thì:

  • 🐌 AI phản hồi chậm dần do token tích lũy quá cao
  • 🧠 AI mất tập trung, trả lời lan man vì bị pha loãng bởi các nhánh suy nghĩ phụ
  • 💸 Tốn token khi Claude/GPT phải đọc lại toàn bộ lịch sử mỗi lượt
💡 Ví dụ thực tế: Bạn đang dựng kịch bản video, tự dưng nảy ý muốn hỏi AI về cách chọn B-roll. Nếu hỏi ngay tại luồng hiện tại, AI sẽ xử lý xong rồi "dính" luôn vào mood câu hỏi phụ đó — quên mất bức tranh tổng thể kịch bản.

RENHANH giải quyết triệt để: tách câu hỏi phụ ra thành 1 luồng chat mới trên Sidebar. Luồng gốc giữ sạch 100%, bạn tiếp tục làm việc không gián đoạn.

2. Cách dùng

Gõ mantra vào khung chat Antigravity:

RENHANH: Tìm cho tôi 5 ý tưởng cảnh trám đoạn hook này

AI sẽ tự động:

  1. Đóng gói bối cảnh hiện tại (3-5 gạch đầu dòng cốt lõi)
  2. Tạo 1 cuộc trò chuyện mới trên Sidebar với tên [Nhánh] ...
  3. In link cho bạn bấm vào → rảnh tay tiếp tục luồng gốc
⚠️ Nguyên tắc tối thượng: AI ở luồng gốc CHỈ tạo nhánh rồi DỪNG LẠI. Nó không được phép đọc file, sửa code, hay phân tích bất kỳ thứ gì liên quan đến task. Toàn bộ công việc do agent ở luồng mới xử lý.

4. Source Code: re_nhanh.py V3 Audit-Hardened

Yêu cầu: Python 3.8+. Không cần cài thêm thư viện ngoài.

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
re_nhanh.py V3 — Rẽ nhánh tư duy Antigravity (Audit-Hardened)
==============================================================
- Đọc Project ID trực tiếp từ env (0 latency).
- Xóa ANTIGRAVITY_SOURCE_METADATA → fix lỗi ẩn khỏi Sidebar.
- Fallback chain: env → metadata → hardcoded path.
"""

import sys, os, json, subprocess, argparse, urllib.parse

AGENTAPI = os.path.expanduser("~/.gemini/antigravity/bin/agentapi")


def get_metadata(cid: str) -> dict:
    """Fallback: lấy metadata qua agentapi."""
    try:
        res = subprocess.run(
            [AGENTAPI, "get-conversation-metadata", cid],
            capture_output=True, text=True, timeout=10
        )
        data = json.loads(res.stdout)
        return data.get("response", {}).get("conversationMetadata", {}).get("metadata", {})
    except Exception as e:
        print(f"[re_nhanh] Error: {e}", file=sys.stderr)
        return {}


def resolve_workspace(env: dict, parent_cid: str) -> str:
    """Xác định thư mục workspace chính xác nhất."""
    # 1. Từ conversation metadata
    if parent_cid:
        meta = get_metadata(parent_cid)
        uris = meta.get("workspaceUris", [])
        if uris:
            uri = uris[0]
            if uri.startswith("file://"):
                path = urllib.parse.unquote(uri[7:])
                if os.path.isdir(path):
                    return path
    # 2. Từ cwd hiện tại
    cwd = os.getcwd()
    if cwd and cwd != "/" and os.path.isdir(cwd):
        return cwd
    # 3. Fallback
    return os.path.expanduser("~/Documents/CODE")


def re_nhanh(title, prompt, parent_cid, model="pro_high"):
    # === 1. Chuẩn bị env (CHỈ COPY 1 LẦN) ===
    env = os.environ.copy()

    # Lấy project_id: ưu tiên env, fallback metadata
    project_id = env.get("ANTIGRAVITY_PROJECT_ID", "")
    if not project_id and parent_cid:
        meta = get_metadata(parent_cid)
        project_id = meta.get("projectId", "")

    # XÓA SOURCE_METADATA → fix lỗi ẩn khỏi sidebar
    env.pop("ANTIGRAVITY_SOURCE_METADATA", None)
    env.pop("ANTIGRAVITY_TRAJECTORY_ID", None)

    if project_id:
        env["ANTIGRAVITY_PROJECT_ID"] = project_id

    # === 2. Workspace ===
    cwd = resolve_workspace(env, parent_cid)

    # === 3. Tiêu đề ===
    if not title.startswith("[Nhánh]"):
        title = f"[Nhánh] {title}"

    # === 4. Model tier ===
    agentapi_model = "pro" if model == "pro_high" else model
    if model == "pro_high" and not prompt.startswith("/boost"):
        prompt = "/boost\n" + prompt

    # === 5. Tạo conversation ===
    cmd = [
        AGENTAPI, "new-conversation",
        f"--model={agentapi_model}",
        f"--title={title}",
        prompt
    ]

    res = subprocess.run(cmd, env=env, cwd=cwd, capture_output=True, text=True)
    if res.returncode != 0:
        return {"status": "error", "error": res.stderr.strip() or res.stdout.strip()}

    try:
        out = json.loads(res.stdout)
        new_cid = (out.get("response", {})
                      .get("newConversation", {})
                      .get("conversationId", ""))
        if not new_cid:
            return {"status": "error", "error": "No conversationId returned"}
        return {
            "status": "success",
            "conversationId": new_cid,
            "title": title,
            "projectId": project_id,
            "workspace": cwd,
            "link": f"conversation://{new_cid}"
        }
    except Exception as e:
        return {"status": "error", "error": str(e)}


def main():
    parser = argparse.ArgumentParser(description="Antigravity Branch Creator V3")
    parser.add_argument("--title", required=True)
    parser.add_argument("--parent-cid", required=True)
    parser.add_argument("--prompt", help="Nội dung prompt trực tiếp")
    parser.add_argument("--prompt-file", help="File chứa prompt (ưu tiên hơn --prompt)")
    parser.add_argument("--model", default="pro_high",
                        choices=["flash_lite", "flash", "pro", "pro_high"])
    args = parser.parse_args()

    prompt_text = None
    if args.prompt_file and os.path.exists(args.prompt_file):
        with open(args.prompt_file, "r", encoding="utf-8") as f:
            prompt_text = f.read()
    elif args.prompt:
        prompt_text = args.prompt

    if not prompt_text:
        print(json.dumps({"status": "error", "error": "Thiếu --prompt hoặc --prompt-file"}))
        sys.exit(1)

    result = re_nhanh(args.title, prompt_text, args.parent_cid, args.model)
    print(json.dumps(result, ensure_ascii=False, indent=2))
    sys.exit(0 if result.get("status") == "success" else 1)


if __name__ == "__main__":
    main()

6. Bug đã xử lý trong V3

🐛 Bug 1: Nhánh mới bị ẩn khỏi Sidebar

Nguyên nhân: Khi agentapi new-conversation được gọi bên trong 1 tool call của agent, Antigravity tự động gắn biến ANTIGRAVITY_SOURCE_METADATA vào metadata của conversation mới. UI nhìn thấy field này → coi conversation là "con sinh bởi tool" → ẩn.

Fix: Script xóa ANTIGRAVITY_SOURCE_METADATA và ANTIGRAVITY_TRAJECTORY_ID khỏi env trước khi gọi agentapi.

🐛 Bug 2: Agent làm task ngay tại luồng gốc

Nguyên nhân: SKILL.md V1-V2 viết lệnh cấm quá yếu, đặt ở cuối file. AI đọc xong phần hướng dẫn đã bắt tay vào làm task trước khi tới dòng "DỪNG LẠI".

Fix: V3 đặt blockquote cảnh báo và danh sách 5 hành vi bị HARD BLOCK ngay dòng đầu tiên của file.

🐛 Bug 3: Gọi agentapi thừa (chậm 500ms)

Nguyên nhân: Script V1 luôn gọi get-conversation-metadata để lấy projectId, trong khi biến này đã nằm sẵn trong env ANTIGRAVITY_PROJECT_ID.

Fix: Đọc trực tiếp từ env, chỉ fallback gọi metadata khi env rỗng.

7. FAQ

Cần cài thêm thư viện Python nào không?

Không. Script chỉ dùng thư viện chuẩn (json, subprocess, argparse, os).

Có cần MCP server không?

Không. Script gọi trực tiếp binary agentapi có sẵn trong Antigravity, không qua mạng.

Model mặc định là gì?

pro_high = Gemini Pro + inject /boost đầu prompt để kích hoạt Deep Thinking budget cao nhất. Bạn có thể đổi sang flash nếu task đơn giản.

Tốn bao nhiêu token mỗi lần RENHANH?

Khoảng 3.000-3.500 token (tương đương 4-5 lượt hỏi đáp thường). Rất nhẹ.

Hoạt động trên Windows không?

Chưa test. Lý thuyết hoạt động nếu Antigravity for Windows có binary agentapi tương đương tại %USERPROFILE%\.gemini\antigravity\bin\agentapi.exe.
