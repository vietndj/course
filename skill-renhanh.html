1. Vấn Đề Của Việc Quá Tải Context

Khi làm việc trên các Agent AI, cuộc trò chuyện càng dài thì AI phản hồi càng chậm (do Token đội lên cao), đồng thời độ "sắc bén" của AI cũng giảm sút vì bị pha loãng bởi các luồng suy nghĩ phụ.

"Thử tưởng tượng bạn đang tập trung làm 1 kịch bản cực cuốn, tự dưng nảy ra một ý tưởng khác và đi sâu vào nó. Sau khi hỏi xong, AI bị dính luôn vào cái mood của câu hỏi phụ, quên mất bức tranh tổng thể của luồng gốc."

Đó là lý do chúng ta cần 2 mantra tối thượng: RENHANH và SANGTRANG.

  • RENHANH (Rẽ Nhánh): Dùng khi muốn AI đào sâu một ngách nhỏ, nhưng KHÔNG MUỐN nó in câu trả lời ra làm bẩn luồng hiện tại. AI sẽ tự tạo một nhánh mới trên Sidebar.
  • SANGTRANG (Lật Trang): Dùng khi luồng đã quá dài, giật lag. AI sẽ đóng gói 3-5 gạch đầu dòng cốt lõi, lật sang luồng mới sạch sẽ 100% token nhưng vẫn nhớ rõ mình đang làm gì.

2. Cú Pháp Hoạt Động Của Agent

Bạn chỉ cần ném Mantra vào khung chat như sau:

RENHANH: Tìm cho tôi 5 ý tưởng cảnh trám đoạn hook này
SANGTRANG: Chốt kịch bản, giờ chuyển qua tư duy setup ánh sáng

Ngay lập tức, AI Agent sẽ tự động trích xuất ngữ cảnh, đóng gói vào 1 Capsule, chạy lệnh Python ngầm và in ra link nhánh rẽ cho bạn bấm vào.

3. Cài Đặt Script Điều Phối (re_nhanh.py)

Script Python này là trái tim của hệ thống. Nó chịu trách nhiệm gọi AgentAPI để tạo luồng mới, giữ nguyên Project ID và xoá các metadata thừa để đảm bảo Conversation hiện đàng hoàng trên Sidebar thay vì bị ẩn.

Lưu file này tại: /Users/vietmac/Documents/CODE/Quản gia/re_nhanh.py

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
import sys, os, json, subprocess, argparse, urllib.parse

AGENTAPI = "/Users/vietmac/.gemini/antigravity/bin/agentapi"

def re_nhanh(title: str, prompt: str, parent_cid: str, model: str = "pro_high"):
    # Tối ưu: Lấy trực tiếp từ biến môi trường
    env = os.environ.copy()
    project_id = env.get("ANTIGRAVITY_PROJECT_ID", "")
    cwd = os.getcwd() if os.getcwd() != "/" else "/Users/vietmac/Documents/CODE"
        
    # Xóa SOURCE_METADATA để tránh luồng mới bị Antigravity UI đánh dấu ẩn (do tool call sinh ra)
    env.pop("ANTIGRAVITY_SOURCE_METADATA", None)
    env.pop("ANTIGRAVITY_TRAJECTORY_ID", None)
    if project_id: env["ANTIGRAVITY_PROJECT_ID"] = project_id
        
    if not title.startswith("[Nhánh]"): title = f"[Nhánh] {title}"
        
    # Inject /boost để chạy mode deep thinking nếu dùng model cao
    agentapi_model = "pro" if model == "pro_high" else model
    if model == "pro_high" and not prompt.startswith("/boost"):
        prompt = "/boost\n" + prompt
        
    cmd = [AGENTAPI, "new-conversation", f"--model={agentapi_model}", f"--title={title}", prompt]
    res = subprocess.run(cmd, env=env, cwd=cwd, capture_output=True, text=True)
    
    if res.returncode != 0: return {"status": "error", "error": res.stderr}
    try:
        out = json.loads(res.stdout)
        new_cid = out.get("response", {}).get("newConversation", {}).get("conversationId", "")
        return {"status": "success", "conversationId": new_cid, "link": f"conversation://{new_cid}"}
    except Exception as e:
        return {"status": "error", "error": str(e)}

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--title", required=True)
    parser.add_argument("--parent-cid", required=True)
    parser.add_argument("--prompt-file", required=True)
    args = parser.parse_args()
    
    with open(args.prompt_file, "r") as f:
        prompt_text = f.read()
        
    res = re_nhanh(args.title, prompt_text, args.parent_cid)
    print(json.dumps(res, indent=2))

4. Cài Đặt File SKILL (Hướng Dẫn AI)

Tạo file ~/.gemini/config/skills/renhanh/SKILL.md cho Antigravity. File này quy định rõ cho AI biết phải làm gì khi người dùng gõ mantra.

---
name: re-nhanh
description: "Mantra: RENHANH hoặc SANGTRANG. Chuyên tạo nhánh hoặc lật trang."
---

# QUY TRÌNH XỬ LÝ (Agent bắt buộc tuân theo)

Khi thấy `RENHANH: [chủ đề]`:
1. Viết Context Capsule (Bối cảnh 3 gạch đầu dòng từ luồng cũ) ra file `/tmp/re_nhanh_prompt.txt`.
2. Chạy tool gọi: `python3 re_nhanh.py --title="[Nhánh]..." --parent-cid="..." --prompt-file="/tmp/re_nhanh_prompt.txt"`
3. In ra link `conversation://ID` cho user bấm vào.
4. TUYỆT ĐỐI DỪNG LẠI NGAY LẬP TỨC. KHÔNG TRẢ LỜI CÂU HỎI Ở LUỒNG NÀY.

Khi thấy `SANGTRANG: [chủ đề]`:
Tương tự, nhưng đặt tên là `[Tiếp nối]...` và yêu cầu user chuyển hẳn sang luồng mới để giải phóng bộ nhớ.

Lưu ý: Bắt buộc tuân thủ bước 4 (Dừng lại) để giữ sạch luồng gốc 100%.
